          01 · Exam Q1

          Classes and objects

          A class is a blueprint for making objects. It bundles the data each object holds (attributes) with the functions that work on that data (methods). Every object you build from it is an instance with its own values. __init__ runs automatically when you create one, and self means "the particular object this method was called on".

          Remember
            
      
          • Class = blueprint (Dog). Object / instance = a thing built from it (Dog("Rex", 3)).
            • 
      
          • Attributes are data stored on the object (d.name). Methods are functions defined in the class (d.speak()).
            • 
      
          • __init__ sets each new object's starting attributes. self is the object the method is working on.
            • 
      
          • Why bother: you write the logic once and reuse it for as many objects as you need, each keeping its own data.
            • 
    
          
    
          Common mistake
          "A class groups code together" is too vague to earn full credit. Say what it groups and why: data and the functions that act on it, as a template for creating objects.
          
  
          
  
          
  

          



          
  
          02 · Exam Q2, Q5
          Namespaces: global vs local
          
  
          A namespace is a lookup table from names to values. The global namespace holds names created at the top level of your file and lasts for the whole program. Every function call gets its own fresh local namespace for its parameters and the variables it assigns, and it's thrown away when the function returns. To find a name, Python checks Local, then Enclosing, Global, and Built-in, in that order (LEGB).

          Remember
            
      
          • Global: created at the top level, visible anywhere in the file, lasts the whole run.
            • 
      
          • Local: created inside a function call (parameters and assignments), visible only inside it, discarded when it returns.
            • 
      
          • Assigning to a name inside a function makes a new local variable, even if a global with the same name exists. Use global a to change the global one instead.
            • 
      
          • Reading a name the function never assigned falls back to the global one (LEGB).
            • 
    
          
    
          Common mistake
          Question 5 prints two lines: 18 and then 0. Writing only 18 forgets the second print. Writing 6 for print(a) assumes the function changed the global, which it can't without global a.
          
  
          
  
          
  

          



          
  
          03 · Exam Q3
          Handling errors with try / except
          
  
          Some errors only show up while the program runs: bad input, a missing file, dividing by zero. These are exceptions, and an unhandled one crashes the program. try/except lets you catch an exception and respond to it instead of crashing. Code that might fail goes in try. If it raises an error, Python jumps straight to the matching except block. The optional else runs only if nothing failed, and finally runs every time.

          Remember
            
      
          • try: code that might raise an exception.
            • 
      
          • except SomeError: runs only if that error happens in try. The rest of the try block after the error is skipped.
            • 
      
          • else: runs only if no exception happened. finally: always runs (cleanup, like closing a file).
            • 
      
          • Purpose in one sentence: handle runtime errors gracefully so the program doesn't crash.
            • 
    
          
    
          Common mistake
          except doesn't "try" anything. It is skipped completely unless an error happens inside try, and then only the first matching except runs.

          05 · Exam Q6
          Loops that stop themselves: while True and break
          
  
          while True: starts a loop that would run forever, so something inside it has to stop it. That's break: it exits the loop immediately. This pattern keeps asking for input until the user signals they're done. input() always returns a string, and pressing Enter on an empty line returns the empty string "".

          Remember
            
      
          • while True + break = "repeat until a stop condition", checked in the middle of the loop.
            • 
      
          • break exits only the innermost loop; the code after the loop runs next.
            • 
      
          • The check if city == "" comes before the print, so the blank entry is never echoed.
            • 
      
          • Indentation decides what's inside the loop.

          Common mistake
          "What is the purpose" wants the whole loop's job, not one line's output. Say it: keeps asking for city names and prints each one as "City: name", until the user enters a blank line.
          
  
          
  
          
  

          



          
  
          06 · Exam Q7, Q9, Q10
          Indexing and slicing strings
          
  
          Every character has an index, starting at 0. Negative indexes count from the end, so -1 is the last character. A slice s[start:end:step] takes characters from start up to but not including end, jumping by step. Leave start or end blank to go all the way to that edge; leave step blank and it's 1. A negative step walks backward.

          Remember
            
      
          • Indexes start at 0: s[0] is the first character, s[-1] the last.
            • 
      
          • The end index is excluded, so s[1:5] has 5 − 1 = 4 characters.
            • 
      
          • s[::2] takes every other character starting at index 0. s[::-1] reverses the string.
            • 
      
          • Spaces and punctuation count. In "Hello, World!" the comma is index 5 and the space is index 6.
            • 
    
          
    
          Common mistake
          Including the character at the end index. "Hello, World!"[1:5] is ello, not ello,. And s[::2] returns characters, not a count: 13579, not 3.
          
  
          
  
          
  

          



          
  
          07 · Exam Q8
          String methods return new strings
          
  
          Strings come with built-in methods you call with a dot. s.replace(old, new) gives back a copy of s with every old swapped for new. Strings are immutable: a method never changes s itself, it hands you a new string. Everything you didn't replace stays exactly as it was, punctuation included.
          
  
          
    
          Method explorer
          watch s stay the same
          
    
          
    
          
    
          
      
      
    
          
    
          
    
          
  
          
  
          
    
          Remember
            
      
          • Methods are called with a dot: s.upper(), s.replace("a", "b").
            • 
      
          • They return a new value; s only changes if you reassign it: s = s.replace(...).
            • 
      
          • replace swaps every match and is case-sensitive: "world" won't match "World".
            • 
    
          
    
          Common mistake
          Dropping characters you didn't touch. "Hello, World!".replace("World", "Universe") keeps the exclamation mark: Hello, Universe!

          08 · Exam Q11
          Deterministic vs probabilistic models
          
  
          A deterministic model says y is exactly determined by x: y = β₀ + β₁x. Plug in x and you get one answer, every time, with no error. A probabilistic model adds a random error term: y = β₀ + β₁x + ε. Real data never land exactly on a line, because things you didn't measure push each point up or down. Regression uses probabilistic models, and ε ("epsilon") is that unexplained part.
          
  
          
    
          Turn up the randomness
          24 simulated students
          
    
          
      
          
      
          
    
          
    
          
    
          MODEL–
          
    
          
      
          Points exactly on the line–
          
      
          Average miss |ε|–
          
    
          
  
          
  
          
    
          Remember
            
      
          • Deterministic: no error term, a perfect prediction. Fits exact laws, like converting °C to °F.
            • 
      
          • Probabilistic: y = β₀ + β₁x + ε. ε is random variation plus everything x doesn't explain.
            • 
      
          • ε averages out to 0, so the line predicts the average y for each x.
            • 
      
          • Regression uses probabilistic models because real data always scatter around the line.
            • 
    
          
    
          Common mistake
          "Probabilistic" doesn't mean the model is a guess or the relationship is weak. It means the model admits that individual points scatter around the line.
          
  
          
  
          
  

          



          
  
          09 · Exam Q12
          The least squares method
          
  
          Many lines could pass through a cloud of points. Least squares picks the one with the smallest sum of squared residuals (SSE). A residual is one point's vertical miss: observed y minus predicted ŷ. Squaring stops positive and negative misses from canceling out and punishes big misses more. Two formulas then give the best slope and intercept directly.

            10 · Exam Q13
            The four steps of regression modeling
            
  
            Regression is a process, not one formula. You specify a model, estimate its numbers from data, evaluate whether it's any good, and only then use it to predict. Skipping step 3 is how people end up confidently predicting with a model that doesn't fit.
            
  
            
    
            Put the steps in order
            tap them first to last
            
    
            
    
            
  
            
  
            
    
            One example, all four steps
            12 students: hours studied vs exam score
            
    
            
    
            
    
            
    
            
    
            
  
            
  
            
    
            Remember
              
      
            • 1 Specify: pick the variables and the form, e.g. y = β₀ + β₁x + ε.
              • 
      
            • 2 Estimate: use sample data, usually least squares, to get b₀ and b₁.
              • 
      
            • 3 Evaluate: check the fit: residuals, R², whether the slope is significantly different from 0.
              • 
      
            • 4 Use: predict y for new x values, inside the range of the data.
              • 
    
            
    
            Common mistake
            Courses word these steps differently, and some textbooks list five (adding "describe the error ε" after estimating). Match your lecture slides' wording on the exam; the logic is the same.

            11 · Exam Q14
            Symbolic vs connectionist AI
            
  
            There are two classic ways to build intelligence. Symbolic AI (sometimes called GOFAI, "good old-fashioned AI") has people write explicit rules and logic over symbols: IF fever AND rash THEN measles. Connectionist AI builds networks of simple connected units, artificial neurons, that learn patterns from examples by adjusting the strength (weight) of each connection. One is programmed; the other is trained.

            SymbolicConnectionist
            
      
            Knowledge comes fromPeople writing rulesLearning from lots of examples
            
      
            Stored asReadable symbols, rules, logicNumbers (weights) spread across a network
            
      
            Inspired byLogic and human reasoningNeurons in the brain
            
      
            StrengthsTransparent, explainable, precise reasoning, little data neededHandles messy input (images, speech, text), improves with data
            
      
            WeaknessesBrittle: fails on cases no rule covers; rules are slow to writeNeeds lots of data and computing power; hard to explain ("black box")
            
      
            ExamplesExpert systems (MYCIN), rule-based chess engines, logic programsDeep neural networks: image recognition, speech, large language models
            
    
            
  
            
  
            
    
            A symbolic spam filter
            type a message or pick one
            
    
    
            
      
      
      
      
    
            
    
            
      
            
      
            VERDICT–
            
    
            
    
            Every decision comes with its reason, which is symbolic AI's strength. But "free for lunch" gets flagged and "c@sh" slips through: nobody wrote a rule for those cases. A connectionist filter would learn from thousands of labeled emails instead, catching variations no one listed but unable to point to one rule as its reason.
            
  
            
  
            
    
            Remember
              
      
            • Symbolic: explicit, human-written rules; transparent; brittle; struggles with perception and ambiguity.
              • 
      
            • Connectionist: learns from data as weights; robust to noisy input; needs lots of data and compute; hard to interpret.
              • 
      
            • Most modern AI is connectionist (deep learning). Neuro-symbolic research tries to combine both.
              • 
    
            
    
            Common mistake
            Saying connectionist AI "has no rules". It follows exact math; the difference is that its behavior is learned into weights instead of written as readable IF-THEN rules.
            
  
            
  
            
  

            



            
  
            12 · Exam Q15
            The Turing Test and its limits
            
  
            In 1950 Alan Turing replaced "Can machines think?" with a test he could actually run, the imitation game. A human judge chats by typed text with two hidden partners, one human and one machine. If the judge can't reliably tell which is the machine, the machine passes. It judges intelligence purely by behavior in conversation, which is both its appeal and its weakness.

            13 · Exam Q16
            Weights and biases in a single neuron
            
  
            An artificial neuron multiplies each input by a weight, adds the results, adds a bias, and passes the total through an activation function: output = f(w₁x₁ + w₂x₂ + b). Weights set how much each input matters, and their sign says whether it pushes the output up or down. The bias shifts the threshold, making the neuron easier or harder to fire. Training means adjusting these numbers until the outputs are right.

            Remember

              •

              •
