            01 · Exam Q1

            Classes and objects

            A class is a blueprint for making objects. It bundles the data each object holds (attributes) with the functions that work on that data (methods). Every object you build from it is an instance with its own values. __init__ runs automatically when you create one, and self means "the particular object this method was called on".

            02 · Exam Q2, Q5
            Namespaces: global vs local
            
  
            A namespace is a lookup table from names to values. The global namespace holds names created at the top level of your file and lasts for the whole program. Every function call gets its own fresh local namespace for its parameters and the variables it assigns, and it's thrown away when the function returns. To find a name, Python checks Local, then Enclosing, Global, and Built-in, in that order (LEGB).

            Remember
              
      
            • Global: created at the top level, visible anywhere in the file, lasts the whole run.
              • 
      
            • Local: created inside a function call (parameters and assignments), visible only inside it, discarded when it returns.

            03 · Exam Q3
            Handling errors with try / except
            
  
            Some errors only show up while the program runs: bad input, a missing file, dividing by zero. These are exceptions, and an unhandled one crashes the program. try/except lets you catch an exception and respond to it instead of crashing. Code that might fail goes in try. If it raises an error, Python jumps straight to the matching except block. The optional else runs only if nothing failed, and finally runs every time.

              •

A slice s[start:end:step] takes characters from start up to but not including end, jumping by step. Leave start or end blank to go all the way to that edge; leave step blank and it's 1.             07 · Exam Q8
            String methods return new strings
            
  
            Strings come with built-in methods you call with a dot. s.replace(old, new) gives back a copy of s with every old swapped for new. Strings are immutable: a method never changes s itself, it hands you a new string. Everything you didn't replace stays exactly as it was, punctuation included.

            08 · Exam Q11
            Deterministic vs probabilistic models
            
  
            A deterministic model says y is exactly determined by x: y = β₀ + β₁x. Plug in x and you get one answer, every time, with no error. A probabilistic model adds a random error term: y = β₀ + β₁x + ε. Real data never land exactly on a line, because things you didn't measure push each point up or down. Regression uses probabilistic models, and ε ("epsilon") is that unexplained part.

            Remember
              
      
            • Deterministic: no error term, a perfect prediction. Fits exact laws, like converting °C to °F.
              • 
      
            • Probabilistic: y = β₀ + β₁x + ε. ε is random variation plus everything x doesn't explain.
              • 
      
            • ε averages out to 0, so the line predicts the average y for each x.
              • 
      
            • Regression uses probabilistic models because real data always scatter around the line.
              • 
      
            • Lecture examples: BMI = kg / m² is deterministic (no error term); newborn SBP = 6 × age(days) + ε is probabilistic (ε covers other factors, like birthweight).
              • 
    
            
    
            Common mistake
            "Probabilistic" doesn't mean the model is a guess or the relationship is weak. It means the model admits that individual points scatter around the line.
            
  
            
  
            
  

            



            
  
            09 · Exam Q12
            The least squares method
            
  
            Many lines could pass through a cloud of points. Least squares picks the one with the smallest sum of squared residuals (SSE). A residual is one point's vertical miss: observed y minus predicted ŷ. Squaring stops positive and negative misses from canceling out and punishes big misses more. Two formulas then give the best slope and intercept directly.

              10 · Exam Q13
              The four steps of regression modeling
              
  
              Regression is a process, not one formula. In the lecture's wording: hypothesize the deterministic component and estimate its unknown parameters, specify the probability distribution of the random error and estimate its standard deviation, evaluate the fitted model, and only then use it for prediction and estimation. Skipping step 3 is how people end up confidently predicting with a model that doesn't fit.
              
  
              
    
              Put the steps in order
              tap them first to last
              
    
              
    
              
  
              
  
              
    
              One example, all four steps
              12 students: hours studied vs exam score
              
    
              
    
              
    
              
    
              
    
              
  
              
  
              
    
              Remember
                
      
              • 1 Hypothesize the deterministic component: define the dependent and independent variables and the form (e.g. a straight line), then estimate the unknown parameters b₀ and b₁ with least squares.
                • 
      
              • 2 Specify the probability distribution of the random error term ε and estimate its standard deviation.
                • 
      
              • 3 Evaluate the fitted model: residuals, R², whether the slope is significantly different from 0.
                • 
      
              • 4 Use the model for prediction and estimation, inside the range of the data.
                • 
    
              
    
              Common mistake
              Listing "estimate" as its own step. In the lecture, estimating the parameters is part of step 1, and step 2 is about the error term: its distribution and standard deviation.

              11 · Exam Q14
              Symbolic vs connectionist AI
              
  
              There are two classic ways to build intelligence. Symbolic AI (sometimes called GOFAI, "good old-fashioned AI") has people write explicit rules and logic over symbols: IF fever AND rash THEN measles. Connectionist AI builds networks of simple connected units, artificial neurons, that learn patterns from examples by adjusting the strength (weight) of each connection. One is programmed; the other is trained.

              13 · Exam Q16
              Weights and biases in a single neuron
              
  
              An artificial neuron multiplies each input by a weight, adds the results, adds a bias, and passes the total through an activation function: output = f(w₁x₁ + w₂x₂ + b). Weights set how much each input matters, and their sign says whether it pushes the output up or down. The bias shifts the threshold, making the neuron easier or harder to fire. Training means adjusting these numbers until the outputs are right.

              16 · Lecture: Inside the Glass Box
              Decision trees, overfitting and explainability

The root node is the first split, decision nodes split again, and leaf nodes give the final answer. Grow the tree too deep and it memorizes the training data instead of learning rules: that's overfitting.

              18 · Lecture: The Blueprint of Intelligence
              How a neural network learns
              
  
              Neurons are stacked into an input layer (raw features), hidden layers (extract patterns) and an output layer (the prediction). Training repeats one loop: Predict (forward pass) → Measure error (loss) → Propagate error (backward pass) → Update the weights. "Biology inspired the architecture, but calculus drives the optimization."
              
  
              
    
              Biology → math
              
    
              
      
              BiologyArtificial neuronRole
              
      
              DendritesInputs (x)The raw data entering the system
              
      
              SynapsesWeights (w)The strength or importance of each connection
              
      
              Soma (cell body)Activation functionThe threshold that decides the output
              
      
              AxonOutput (y)The final transmitted signal
              
    
              
  
              
  
              
    
              One training step, number by number
              one neuron · x = 2, target y = 1 · sigmoid · loss = ½(p − y)²
              
    
              
    
              
    
              
      
              
        
              1 · Predict2 · Measure error3 · Propagate error4 · Update
              
        
              
      
              
      
              
    
              
    
              The backward pass uses the lecture's chain rule: Δp = ∂Loss/∂p, then Δz = Δp · ∂p/∂z, then ΔW = Δz · ∂z/∂W and Δb = Δz · ∂z/∂b. Each weight moves against its gradient, scaled by the learning rate.
              
  
              
  
              
    
              Gradient descent: rolling into the valley
              the "landscape of error"
              
    
              
    
              
    
              
    
              Real networks have hundreds of millions of weights ("knobs"). Stochastic gradient descent (SGD) follows the negative gradient, the steepest way downhill, toward the valley where average error is lowest. Too big a step overshoots the valley.
              
  
              
  
              
    
              Two passes, one objective
              
    
              
      
              Forward passBackward pass
              
      
              DirectionLeft to right (input → output)Right to left (output → input)
              
      
              GoalPredict the outcomeCorrect the mistakes
              
      
              Key metricOutput valueGradient / loss
              
      
              ActionCompute data via weightsUpdate weights via error
              
    
              
  
              
  
              
    
              Remember
                
      
              • Loss: how far the prediction is from the actual target. Measuring it is the first step toward learning.
                • 
      
              • A gradient is the rate of change of the error with respect to a weight.
                • 
      
              • Backpropagation sends the error backward and adjusts each weight by its contribution to the mistake.
                • 
      
              • Applications named in the lecture: image recognition, natural language processing, recommendation systems.
                • 
    
              
    
              Common mistake
              Mixing up the mapping: synapses are the weights, not the inputs. The dendrites are the inputs.

              Least squares by hand: the table method

The hats mean estimates from a sample of the unknown population values β₀ and β₁.

                23 · Lecture: CNN Anatomy and Evolution
                ImageNet, AlexNet and VGG
                
  
                The ImageNet challenge (ILSVRC) asked models to sort about 1,000,000 training images into 1,000 categories (50,000 validation images). In 2012 AlexNet (Krizhevsky, Sutskever, Hinton) cut the error from 25.7% to 17.0%, an ~10% drop overnight: end-to-end feature learning beat decades of hand-engineered vision. VGG (2014) then went deeper with only small 3 × 3 filters.
                
  
                
    
                Top-1 vs top-5 error
                the model's ranked guesses for one photo
                
    
                
    
                
    
                
      
                Top-1 error–
                
      
                Top-5 error–
                
    
                
    
                Top-1 counts only the first guess. Top-5 counts it correct if the true label is anywhere in the top 5. In the lecture's example the true label is "Abyssinian cat", ranked 4th: top-1 error 1.0, top-5 error 0.0.
                
  
                
  
                
    
                Shattering the benchmark
                classification error, lower is better
                
    
                
  
                
  
                
    
                Dropout
                each training step drops a random half of the hidden units
                
    
                
    
                
    
                Without dropout, nodes can co-adapt, over-relying on specific neighbors, which leads to overfitting. Randomly zeroing outputs during training forces redundant, robust features.
                
  
                
  
                
    
                The evolution of depth
                
    
                
      
                YearModelRoleKey ideas
                
      
                1998LeNetThe blueprintSmall; alternating convolution and pooling
                
      
                2012AlexNetThe breakthrough5 conv + 3 FC layers (FC8 = 1000 classes); GPU training, ReLU, momentum & weight decay, data augmentation, dropout; error 17%
                
      
                2014VGGThe standardizationSimonyan & Zisserman; only stacked 3 × 3 convs instead of 11 × 11; deeper and simpler
                
    
                
  
                
  
                
    
                Remember
                  
      
                • AlexNet's arsenal: GPU computation, ReLU instead of sigmoid/tanh (fixes vanishing gradients, trains faster), momentum & weight decay, data augmentation, plus dropout.
                  • 
      
                • Data augmentation in the lecture: take random 224 × 224 crops of a 256 × 256 image, so the network sees more variety and learns positional invariance.
                  • 
      
                • Error table: sparse coding 28.2%, SIFT + Fisher vectors 25.7% (best traditional), AlexNet 17.0%.
                  • 
      
                • Later models (GoogLeNet, ResNet, EfficientNet) build on the same blueprint.
                  • 
    
                
    
                Common mistake
                Saying AlexNet invented CNNs. LeNet came 14 years earlier; AlexNet's achievement was scaling the blueprint with GPUs and new training tricks.

                25 · Lectures: Responsible Systems, Glass Box
                Ethics and how bias gets amplified
                
  
                "How's the water?" Ethics in ML isn't about personal feelings or legal compliance; it's seeing the invisible structural environment an algorithm operates in. Models don't just reflect historical bias, they amplify it: biased data trains a biased model, whose actions make the world's data more biased. And a model's output is a prediction; humans make the decisions.
                
  
                
    
                The bias amplification loop: Amazon, 2018
                step around the loop
                
    
                
    
                
    
                
  
                
  
                
    
                COMPAS: "blind" to race, still unequal
                error rates by group
                
    
                
    
                COMPAS predicted re-offending and left race out of its inputs. Its scores matched overall probabilities, yet the errors were lopsided: Black defendants were labeled high-risk without re-offending almost twice as often (44.9% vs 23.5%), while white defendants were more often labeled low-risk and then re-offended (47.7% vs 28.0%).
                
  
                
  
                
    
                Match the ethical theory

                Remember
                  
      
                • Paperclip maximizer: an AI told only to make paperclips converts everything into paperclips. Small objective misalignments compound at scale.
                  • 
      
                • Liability trolley: pulling the lever = 1 death + 1 wrongful-death suit; doing nothing = 5 deaths + 0 liability. Incentives can favor inaction.
                  • 
      
                • A prediction is not a decision: image generators showed CEOs and lawyers as almost all men and cashiers as mostly women. The math was "correct"; the outcome was flawed.
                  • 
      
                • Responsible deployment = model evidence + context + human policy + human review.
                  • 
    
                
    
                Common mistake
                "Remove the protected attribute and the model is fair." COMPAS removed race and its errors were still unequal, because other features carry the same information and base rates differ.
                
  
                
  
                
  

                



                
  
                26 · Lecture: Architecting Responsible Systems
                Fairness trade-offs and their limits
                
  
                There are at least 21 mathematical definitions of fairness, and stakeholders want different ones: a decision-maker wants accurate positives, a defendant wants few false positives, society wants demographic parity. The Chouldechova impossibility theorem, as the lecture states it: if base rates differ between two groups, an algorithm cannot have equal false positive rates and equal false negative rates at the same time.
                
  
                
    
                Try to make a loan model fair
                two groups with different base rates of repaying · simulated
                
    
                
      
                
      
                
    
                
    
                
    
                
    
                
    
                
  
                
  
                
    
                Equality, equity, justice
                
    
                
    
                
    
                
  
                
  
                
    
                Remember
                  
      
                • Demographic parity: equal approval rates. Equal opportunity: equal true positive rates.
                  • 
      
                • Lecture's loan simulation: Max profit 32,400; Demographic parity ~28,000; Equal opportunity ~26,000. Every fairness criterion costs some utility.
                  • 
      
                • Equality = algorithmic blindness (fails). Equity = adjust thresholds (costs utility). Justice = fix the base rate, the data-generating process (the only structural fix).
                  • 
      
                • Diverse teams catch bias: Turkish "O bir doktor / O bir hemşire" was translated "He is a doctor / She is a nurse".
                  • 
      
                • Architect's mandate: acknowledge the water, anticipate the trade-offs, engineer the room.
                  • 
    
                
    
                Common mistake
                Hoping to satisfy every fairness metric at once. With different base rates you have to choose which errors to equalize and accept the cost.
